# 三体 · 危机纪元 AI 主理人

《三体 · 危机纪元》AI 互动游戏的正式入口指引页。游戏的 AI 主理人需要在正式站点域名下完成云端鉴权，本仓库即为该单文件静态指引页，负责把访客带往正式入口。

## ✨ 功能特性

- 深空星野视觉：纯 CSS 径向渐变绘制星空，带闪烁动画，契合三体宇宙氛围
- 倒计时自动跳转：页面加载后 3 秒跳转至正式站点（`meta refresh` + 定时器），并有秒数实时递减提示
- 手动入口兜底：自动跳转未生效时，可点击「进入正式入口」按钮前往
- 单文件零依赖：纯静态页面，无需构建、无需安装任何依赖

## 🚀 使用方法

1. 用浏览器直接打开 `index.html`
2. 页面将在 3 秒后自动跳转至正式入口；若未跳转，点击页面中央的「进入正式入口」按钮
3. 建议收藏跳转后的正式链接，后续无需再经过本指引页

## 🛠️ 技术栈

- HTML / CSS / 原生 JavaScript（单文件，无依赖）
- 部署方式：任意静态托管（如 GitHub Pages）
